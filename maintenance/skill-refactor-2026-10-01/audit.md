## Changes and consequential protections

- Rewrite 23 roots around explicit contracts and conditional knowledge. Keep standards/spec independence, causal diagnosis, credible behavioural oracles, unique test protection, confirmed synthesis, source traceability and scope boundaries.
- Keep product intent, feature solution and ticket execution as distinct lifecycle outputs. Reuse exact complete confirmed handoffs; preserve stable IDs and reciprocal links. Keep glossary aliases while imported evidence uses them and ADR eligibility/consent for consequential choices.
- Move ticket estimation from an output asset to a conditional reference. Separate code-review axis criteria and shared review rules without duplicating their meanings. Remove repeated choreography and needless fresh-agent compulsion from commit and routine research; retain fresh independent diagnostic review where its contract requires it.
- Preserve Git staging, hooks, base/head revisions, unknown-outcome readback, one-PR publication, reproducible dependency/lockfile migration and evidence limits. All external-action evaluations use stub services and local bare repositories.
- Remove conflicting `disable-model-invocation` client fields from 23 portable roots. Codex adapters retain all original implicit/explicit policies: four implicit, twenty explicit. Current Claude documentation says the removed field also blocks tool composition; Codex's supported adapter expresses the intended policy. Other clients must use their supported adapter. No cross-client enforcement claim is made.
- Strengthen architecture report validation per recommendation, including parsed attributes, legitimate quote styles, visible fields after closed evidence, intrinsic hidden ancestors, expandable evidence containment and valid CLI usage. Retain the requested destination, revision, coverage, fixed ranking, evidence/trade-offs and zero-result contract. Structural validation does not establish factual or rendered quality.
- Repair inherited Python nesting accumulation with a per-function AST counter and reset the other-language extension per file. Record method/interpreter and require method-matched baselines. Named functions, lambda bodies, conditional expressions, comprehensions, decorators, async code and unavailable parses have regression coverage. Production scope excludes conventional JavaScript and TypeScript test filenames. Other metrics and vendored Lizard remain pinned. This is a changed measurement method, not a claim that scores identify defects.
- Tighten TDD stub handling: prove a result assertion detects a controlled wrong result when the unimplemented stub stops that assertion from running. Keep valid unexpected-exception evidence when completion is the full promise.
