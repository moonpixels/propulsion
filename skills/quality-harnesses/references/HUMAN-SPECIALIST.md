# Human and Specialist Evidence

## Accessibility

Resolve the applicable product and accessibility authority, changed routes and states, supported input modes, browsers, and assistive technologies. Run configured automation against the actual rendered state, then perform the manual interactions the change exposes: keyboard navigation, visible focus, focus order and restoration, labels and semantics, error identification, zoom and reflow, contrast, motion, and relevant screen-reader or other assistive-technology behaviour.

Record route, state, content, viewport, zoom, theme, browser, platform, assistive technology and version, automated rules, manual steps, expected outcome, actual outcome, and captures where useful. Inspect hidden states, disabled elements, overlays, asynchronous updates, rule suppressions, partial keyboard paths, and tests against non-production markup.

Automation supports only enabled rule checks. Manual results support only the exercised environment and evaluator capability. Neither alone establishes conformance or usability across users and technologies; unavailable required coverage remains an explicit gap.

## Manual and specialist QA

Use a reproducible manual procedure when automation cannot faithfully observe a material visual, physical, usability, domain, data, compliance, or contextual result. Use specialist assessment only when the claim requires knowledge the current caller and executable harnesses do not supply; do not simulate or invent that expertise.

Define the claim, inputs, initial state, environment, steps, expected result from an independent authority, observation method, cleanup, and acceptable variation before execution. Preserve actual results, captures or measurements, versions, repetitions where variability matters, deviations, and the evaluator's relevant capability or limitation.

A recorded observation supports only that procedure and context. Subjectivity, evaluator knowledge, unavailable equipment or data, and untested states remain limitations. When the required person, environment, service, device, data, or authority is unavailable, mark the claim unassessed and return the residual risk to the caller; do not install infrastructure, fabricate a result, or convert generic inspection into specialist approval.

Representative contrast: a database specialist can assess lock duration and operational backfill safety from production-scale evidence; an implementation agent reading the migration can identify questions but cannot claim that specialist assessment occurred.
